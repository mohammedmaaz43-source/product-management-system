# Product Management System

A web-based Product Management System developed using PHP and MySQL.

Add your live website URL here.

## Project Overview

The Product Management System is designed to manage products, customers, orders, payments, suppliers, categories and product listings through separate Admin and Customer modules.

## Features

### Admin Module

- Admin Dashboard
- Product Management
- Add Product
- Edit Product
- Delete Product
- Product Details
- Category Management
- Supplier Management
- Customer Order Management
- Order Status Management
- Payment Information
- Reports
- Admin Profile

### Customer Module

- Customer Dashboard
- Browse Products
- Product Details
- Product Reviews and Ratings
- Shopping Cart
- Checkout
- Payment
- Payment Receipt
- Order Success
- My Orders
- My Products
- Sell Product
- My Listings
- Reports
- Customer Profile

## Payment System

The system supports:

- UPI
- Card
- Cash on Delivery

Payment information includes:

- Payment Method
- Payment Status
- Transaction ID
- Payment Date
